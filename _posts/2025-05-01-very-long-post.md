# Introduction

This is a sample post to demonstrate how posts work in Jekyll. You can write your content using Markdown. Markdown makes it easy to format text, include code snippets, and structure your content without the complexity of HTML.

Blogging with Jekyll offers flexibility, especially for developers and tech-savvy writers who prefer to keep things simple and version-controlled. Whether you're maintaining documentation, writing how-to guides, or sharing thoughts on technology, Jekyll gives you a minimal yet powerful platform to do so.

# Why Use Jekyll?

Jekyll is a static site generator that transforms your Markdown files into a complete website. It’s widely used for:

- Developer portfolios
- Personal blogs
- Project documentation
- Company landing pages
- Technical content platforms

The simplicity of Jekyll comes from its use of layouts, includes, and Markdown content. Combined with GitHub Pages, it’s one of the easiest ways to host a personal website for free.

# Getting Started

To start a new Jekyll project:

1. Install Ruby and Jekyll.
2. Run `jekyll new my-awesome-site`
3. Navigate to your directory and run `bundle exec jekyll serve`
4. Visit `localhost:4000` in your browser
